Windows Jump List Parser

Drop in a .automaticDestinations-ms or .customDestinations-ms file (found under %AppData%\Microsoft\Windows\Recent\AutomaticDestinations) to see the recent and pinned shortcuts an app has recorded: target path, pin order, access count, last-modified time.

Drop a jump list file here, or click to choose
.automaticDestinations-ms or .customDestinations-ms

How this works: this page reads the Compound File Binary (OLE2) container format and the embedded Shell Link (.lnk) entries directly in your browser tab, with plain JavaScript. No WebAssembly, no CDN dependency, nothing uploaded — your file is never sent anywhere.

Accuracy note: the container format and the shortcut format are both public specifications, and are parsed strictly. The "DestList" metadata (pin order, access count, recorded path) uses a format Microsoft has never published, reverse-engineered by the forensics community — it's offered as best-effort supplementary detail; if it can't be parsed cleanly, the shortcuts are still shown from their own data.
